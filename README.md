# Stunt Car Extreme

Offline-ready build of Stunt Car Extreme: ZZ loading screen, no ads, iPad/touch tuned.
The engine is embedded in `index.html`; level bundles load from `StreamingAssets/`.

Play: https://zz-games.github.io/Stunt-Car-Extreme/

Serve it over http (GitHub Pages or `python3 -m http.server`); opening index.html straight from disk can't load the level bundles.
